MousePilot — 마우스 휠과 제스처로 브라우저를 다룹니다.
브라우저 탭바 위에서 마우스 휠을 돌리면 탭이 바뀝니다.
(휠 아래 = 오른쪽 탭, 휠 위 = 왼쪽 탭. 포커스가 없거나 뒤에 있는 창에서도 동작)
마우스 제스처: 브라우저 창 위에서 오른쪽 버튼을 누른 채 그으면 뒤로·앞으로·탭 닫기 등이 실행됩니다.
(긋지 않고 오른쪽 클릭하면 버튼을 놓을 때 메뉴가 뜹니다. 자체 마우스 제스처가 있는 브라우저(Vivaldi, Opera 등)는 제외)
지원: Brave, 웨일, Chrome, Safari, Edge, Vivaldi, Opera, Firefox, Arc

설치 / 업데이트
1. MousePilot.app 을 옆의 Applications 폴더로 끌어다 놓습니다. (업데이트면 덮어쓰기)
2. 응용 프로그램 폴더에서 MousePilot 을 엽니다.
   "확인되지 않은 개발자" 경고로 열리지 않으면:
   시스템 설정 → 개인정보 보호 및 보안 맨 아래의 "그래도 열기" 를 누르고 다시 엽니다.
3. 손쉬운 사용 권한 요청이 뜨면 허용합니다.
   (시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 → MousePilot 켜기)
4. 메뉴바의 MousePilot 아이콘이 선명해지면 동작 중입니다.
5. 뒤쪽 창의 탭바에서 처음 휠을 돌리거나 ↓← 제스처(시크릿창에서 열기)를 처음 쓰면
   "MousePilot이(가) ...을(를) 제어하려고 합니다" 창이 브라우저마다 한 번 뜹니다. 허용하면 됩니다.

메뉴바 아이콘: 일시정지 / 순환 켜고 끄기 / 휠 방향 반대로 / 마우스 제스처(제스처 설정) / 적용 브라우저 선택 /
로그인 시 자동 실행 / 종료
Chromium 계열 브라우저 설정에서 "Ctrl-Tab 으로 최근 사용한 탭 순환" 이 켜져 있으면
탭 순서가 뒤섞이니 꺼 주세요.
